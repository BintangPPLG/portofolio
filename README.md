## ✦ Overview

Personal portfolio website for **Narendra Bintang Ramadan**, a Software Engineering student at **SMK Taruna Bhakti Depok**. Engineered with a clean editorial design aesthetic, refined typography, authentic vector brand icons, and fluid hardware-accelerated animations.

### ✨ Highlights & Key Features

- **Refined Typography & Modern Aesthetic**: Non-bold, balanced type scale utilizing *Inter Variable* and *JetBrains Mono* with optical letter tracking.
- **Calm, Intentional Motion**: Custom Apple-grade bezier entrance transitions (`[0.16, 1, 0.3, 1]`) and responsive micro-interactions powered by Framer Motion.
- **Crisp Vector Tech Stack**: Precise, authentic SVG logos with categorized filtering for Frontend, Backend, Mobile, and DevOps tools.
- **Adaptive Theming**: Seamless Light &amp; Dark mode with automated persistence and zero layout flashes.
- **Fully Accessible &amp; Responsive**: Keyboard-friendly navigation, semantic HTML5 structure, and mobile-first responsive drawer layout.
- **Direct Curriculum Vitae**: Built-in direct download for latest verified CV and resume PDF.

## 🚀 Getting Started Locally

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18 or higher recommended)
- [npm](https://www.npmjs.com/) or [pnpm](https://pnpm.io/)

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/BintangPPLG/portofolio.git
   cd portofolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```
